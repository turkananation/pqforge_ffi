## 5. Recommendation (advice to the human)

**The Sovereign Conclave advises you to** adopt **Option B as the spine, with Option C's
pure-Dart contract + `pqforge`-backed fallback as a co-equal Phase-1 deliverable, and Option A
(FRB) explicitly deferred.** This is not a compromise average — the evidence *eliminates* A
(E5 puts a missing, version-sensitive codegen tool on its critical path; Marshall flagged its
premise UNSUPPORTED), and B and C describe two halves of the **same Phase 1 that is fully
buildable and testable here today with zero dependency on FRB, Go, or aws-lc-rs**:

- **Phase 1a (C's core — validatable now):** Dart backend contract + `PqForgeException` taxonomy
  + pure-Dart fallback wired to `pqforge` (E13) + runtime selector. *This Dart contract is the
  spec the C-ABI must satisfy* — which neutralizes Oppenheimer's "the ABI shape may be wrong"
  counterfactual. Validate: `dart test` green with the native lib **absent**.
- **Phase 1b (B's spine — validatable now, needs only E4 toolchain):** minimal Rust `cdylib` +
  hand-written `extern "C"` + `PqForgeError` C-repr status codes + `pqforge_abi_version` probe +
  an **error-code round-trip** function. The Phase-1 validation bar is **not "it links"** (which
  Oppenheimer rightly called weak) but *"typed errors round-trip correctly through the FFI and
  the fallback passes the real contract tests."* Validate: `cargo test` + a `dart:ffi` smoke test.
- **Phase 2 (gated on the one remaining unobserved item, E6):** aws-lc-rs (non-FIPS) ML-KEM +
  ML-DSA (E14) + `zeroize`/`ZeroizeOnDrop` + `mlock`, behind the **same** C-ABI. Validate: the
  build actually succeeds (this *observes* E6), FIPS 203/204 KAT vectors pass, secrets verified
  zeroed.

**Confidence: HIGH for Phase 1, MEDIUM for Phase 2.** Phase 1 depends on nothing unverified
(toolchain present E4; fallback dep confirmed E13). Phase 2's only open risk is whether the large
non-FIPS aws-lc-rs C build completes locally (E6) — swap covers memory (E3), so the realistic
failure is *time*, not OOM; if it fails, the same C-ABI accepts a pure-Rust crypto crate
(RustCrypto `ml-kem`/`ml-dsa`) or defers the native build to CI, **without touching Phase 1**.
